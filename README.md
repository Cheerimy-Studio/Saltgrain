## 什么是盐粒

盐粒不是币。

它借的是盐的那点意思：

- **一粒很小。** 单独一粒盐什么都不是，撒进锅里才有味道。
- **粒粒相同。** 没有哪一粒盐比别的更贵重，也不该有。
- **多了会咸。** 盐的好不在于多，在于刚好。
- **能存住东西。** 盐腌住时间，让一件事留得久一点。

这条链记的就是这样的东西：谁筛出了一粒，谁把一粒交给了谁，谁在那粒盐上写了句话。它不解决任何问题，也不打算有用。它只是一份同时被很多人看着的账本 —— 一个能在 GitHub 上自己长出内容的容器。

「盐粒」这个名字本身就是结论的一部分：越想让它值钱，它就越没有意义。

## 采盐教程：筛出一粒盐

在这个项目里，采盐就是**筛盐**。机器面前有一串数字，要从里面挑出若干，让它们加起来正好等于一个目标重量。挑对了，就算筛出一粒，这一粒记在筛它的人名下。

### 第 0 步：先给仓库点个 ★ Star

没点 Star 的人提交的盐块会被节点拒绝 —— 这是参与的唯一门槛，和账本本身无关。

### 第 1 步：准备 Python

只需要 Python 3.8 以上，不需要安装任何第三方库。

```bash
python3 --version
```

### 第 2 步：把仓库拿下来

```bash
git clone https://github.com/Cheerimy-Studio/Saltgrain.git
cd Saltgrain
```

后面几步的命令都在这个目录里跑。

### 第 3 步：建一个盐框

```bash
python3 saltbox.py new
```

它会打印一个 `salt1…` 开头的地址，那就是你的收盐地址。私钥会明文写在 `saltbox.json` 里 —— 请把它当成一张随时会丢的废纸，**绝不要用它去做任何正经事**。

### 第 4 步：筛一粒

```bash
python3 miner.py --miner 你的GitHub用户名 --message "想留在盐粒上的一句话"
```

`--miner` 必须是你自己的 GitHub 用户名，机器人会核对提交者的身份。采盐可能要几分钟到几十分钟，屏幕上的进度会告诉你大概还剩多久。

想采得快，就去改求解的算法 —— 这个项目比的从来不是机器好不好，而是想法好不好。这是它唯一认真的一件事。

### 第 5 步：交上去

采完之后，终端会打印一行以 `salt-block-v1:` 开头的内容。把它整行复制，贴到这个仓库的 **[采盐提交处](../../issues/16)** 里，发一条评论。

### 第 6 步：等着

机器人会在一两分钟内回复你。成功的话它会说盐块已被接受，上面的账本自己就更新了 —— 不需要你做任何事。失败的话它会告诉你为什么。

## 把盐寄给别人

```bash
python3 saltbox.py send --to 对方的salt1地址 --amount 1.5 --memo "给"
```

它打印一行 `salt-tx-v1:`，贴到 **[寄送提交处](../../issues/2)**。会有人把它打包进下一个盐块。手续费高的先被拿走。刚筛出来的盐要等十个盐块之后才能动，这是规矩。

## 让账本上出现你的名字

账本里默认只有地址。想让别人看到你的名字：

```bash
python3 saltbox.py identity --handle 你的GitHub用户名
```

把打印出的 `salt-id-v1:` 那行贴到 **[寄送提交处](../../issues/2)**。名字只影响显示，不影响谁真正拥有盐粒 —— 那是私钥说了算的事。

## 自己核验整条账本

不用相信这个页面，也不用相信机器人：

```bash
python3 verify.py
```

它会把整条链从头到尾算一遍。通过就打印一串数字，不通过会明确告诉你哪一块有问题。任何人、任何一台机器，跑出来的结果都一样。

## 规则速览

不用看懂也能玩，但知道这些会舒服一点：

- 每采出一粒奖励 50 SALT，每 **210,000 粒**减半一次。能采的粒数一共 **13,440,000 粒**，发完总量约 **21,000,000 SALT**，之后奖励为 0。
- 按每粒 10 分钟的目标算，第一次减半在约 4 年后，全部采完要 200 多年。
- 奖励要等 10 个盐块成熟后才能花。
- 每 16 个盐块，筛盐的难度自动调整一次，人多了就变难，人少了就变简单。
- 一条链同时只有一个有效版本。别人接不上你的盐块，你的那粒就不算数。

## 提醒

- **盐粒一文不值。** 永远不要花钱买它，也不要拿它当抵押、当承诺、当投资。
- 私钥是明文保存的。**别拿它存任何要紧的东西。**
- 这个仓库是唯一的记账人。你能信它，是因为整条链随时可以被任何人重算一遍，不是因为它承诺了什么。
